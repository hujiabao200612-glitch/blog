abstract_en: "Large language model (LLM)-based agents that reason, plan, and act through tools, memory, and structured interaction are emerging as a promising paradigm for automating complex workflows. Recent systems such as OpenClaw and Claude Code exemplify a broader shift from passive response generation to action-oriented task execution. Yet as agents move toward open-ended, real-world deployment, relying on from-scratch reasoning and low-level tool calls for every task become increasingly inefficient, error-prone, and hard to maintain. This survey examines this challenge through the lens of agent skills, which we define as reusable procedural artifacts that coordinate tools, memory, and runtime context under task-specific constraints. Under this view, agents and skills play complementary roles: agents handle high-level reasoning and planning, while skills form the operational layer that enables reliable, reusable, and composable execution. Skills are therefore central to the scalability, robustness, and maintainability of modern agent systems. We organize the literature around four stages of the agent skill lifecycle -- representation, acquisition, retrieval, and evolution -- and review representative methods, ecosystem resources, and application settings across each stage. We conclude by discussing open challenges in quality control, interoperability, safe updating, and long-term capability management."

## 中文解读

这篇和前两篇是互补关系：如果说自进化回答的是"智能体如何变强"，这篇回答的是"变强的成果以什么形式沉淀下来"——答案是 **skills（技能）**。

核心定义值得记住：skill = 可复用的过程性产物（reusable procedural artifacts），它把工具调用、记忆、运行时上下文打包成任务相关的可执行单元。智能体做高层规划，技能做可靠执行，两者分工。

四个生命阶段：
1. **表示（representation）**：技能长什么样——代码、workflow、prompt 模板？
2. **获取（acquisition）**：技能从哪来——人工编写、从演示中挖掘、智能体自己总结？
3. **检索（retrieval）**：什么时候用什么技能——任务匹配问题；
4. **演化（evolution）**：技能如何更新迭代——这就连回了自进化主题。

和《Agents of Change》对照着看会很有意思：HexMachina 沉淀下来的"编译好的玩家"，本质上就是一个 skill。这篇综述给了你一套语言去描述那种现象。
