abstract_en: "We address the long-horizon gap in large language model (LLM) agents by enabling them to sustain coherent strategies in adversarial, stochastic environments. Settlers of Catan provides a challenging benchmark: success depends on balancing short- and long-term goals amid randomness, trading, expansion, and blocking. Prompt-centric LLM agents (e.g., ReAct, Reflexion) must re-interpret large, evolving game states each turn, quickly saturating context windows and losing strategic consistency. We propose HexMachina, a continual learning multi-agent system that separates environment discovery (inducing an adapter layer without documentation) from strategy improvement (evolving a compiled player through code refinement and simulation). This design preserves executable artifacts, allowing the LLM to focus on high-level strategy rather than per-turn reasoning. In controlled Catanatron experiments, HexMachina learns from scratch and evolves players that outperform the strongest human-crafted baseline (AlphaBeta), achieving a 54% win rate and surpassing prompt-driven and no-discovery baselines. Ablations confirm that isolating pure strategy learning improves performance. Overall, artifact-centric continual learning transforms LLMs from brittle stepwise deciders into stable strategy designers, advancing long-horizon autonomy."

## 中文解读

注意：这篇**不是综述**，而是一篇实证论文（张璐老师邮件里把它和综述并列，但读法完全不同）。

最值得看的是它的设计思想——**把"发现"和"改进"分开**：

1. **环境发现（discovery）**：在没有文档的情况下，让智能体自己诱导出与环境交互的适配层；
2. **策略改进（improvement）**：在适配层之上，通过代码精炼 + 仿真对局，不断演化出更强的"编译好的玩家"。

关键洞察是"可执行产物"（executable artifacts）：HexMachina 沉淀下来的不是提示词或对话历史，而是能直接运行的代码玩家。这样 LLM 就不用每回合重新推理，可以专注在高层策略上。这正好对应了老师"用卡牌/桌游类简单环境验证大模型自我改进和长程规划"的建议——卡坦岛就是那个桌游环境。

从 RL 视角看，一个值得追问的问题是：这里的"进化信号"到底是什么？代码精炼的改进信号和策略梯度的信用分配有什么本质区别？这是把这篇读深的关键。
